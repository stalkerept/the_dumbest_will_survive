Математическое ожидание $\langle X \rangle$ — среднее значение случайной величины:

- Для дискретной величины: $\langle X \rangle = \sum_i x_i P_i$.
- Для непрерывной с плотностью $f(x)$: $\langle X \rangle = \int_{-\infty}^{+\infty} x f(x)\, dx$.

Для произвольной функции $g(X)$ среднее значение:
$$
\langle g(X) \rangle = \int_{-\infty}^{+\infty} g(x) f(x)\, dx
$$

**Примеры**:
- Средняя проекция скорости: $\langle v_x \rangle = \int v_x f(v_x)\, dv_x = 0$ (из симметрии).
- Средний квадрат проекции: $\langle v_x^2 \rangle = \int v_x^2 f(v_x)\, dv_x = kT/m$, используется при нахождении параметра $\alpha$ в распределении Максвелла.

Математическое ожидание — линейная операция: $\langle aX + bY \rangle = a\langle X \rangle + b\langle Y \rangle$.

В статистической физике данное определение применяется для вычисления характеристических скоростей распределения Максвелла. Примеры:
- Средняя скорость: $\langle v \rangle = \int_0^\infty v f(v) dv$ — см. [[Средняя скорость молекулы (вывод через распределение Максвелла)]].
- Средний квадрат скорости: $\langle v^2 \rangle = \int_0^\infty v^2 f(v) dv$ — используется в выводе среднеквадратичной скорости, см. [[Среднеквадратичная скорость (вывод через распределение Максвелла)]].
