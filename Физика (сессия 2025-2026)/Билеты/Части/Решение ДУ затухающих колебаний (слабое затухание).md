При условии слабого затухания ($\beta < \omega_0$) решение дифференциального уравнения
$$
\ddot{x} + 2\beta\dot{x} + \omega_0^2 x = 0
$$
имеет вид затухающего гармонического колебания (для простоты $x_0=0$):
$$
x(t) = A_0 e^{-\beta t} \cos(\omega t + \varphi_0),
$$
где
- $\omega = \sqrt{\omega_0^2 - \beta^2}$ — циклическая частота затухающих колебаний,
- $A_0$ — начальная амплитуда (при $t=0$).

Амплитуда колебаний экспоненциально убывает со временем: $A(t) = A_0 e^{-\beta t}$. Период таких колебаний условный, поскольку процесс не является строго периодическим:
$$
T = \frac{2\pi}{\omega} = \frac{2\pi}{\sqrt{\omega_0^2 - \beta^2}}.
$$
Подстановка данного решения в исходное ДУ показывает, что оно выполняется только при выполнении условия $\omega^2 = \omega_0^2 - \beta^2$.

### Проверка данного уравнения:
$$
\begin{align*}
x(t) = A_{0}e^{-\beta t}\cos({\omega t + \varphi_{0}}) = A_{0}e^{-\beta t}\cos{\Theta} \\
\dot{x}(t) = -\beta A_{0}e^{-\beta t}\cos{\Theta} - \omega Ae^{-\beta t}\sin{\Theta} = -A_{0}e^{-\beta t}(\beta\cos{\Theta} + \omega \sin{\Theta}) \\
\text{Пусть } f(t) = e^{-\beta t}, g(t) = \beta\cos{\Theta} + \omega \sin{\Theta} \\
\dot{x}(t) = -A_{0}f(t)g(t) \implies \ddot{x}(t) = -A_{0}(\dot{f(t)} g(t) + f(t)\dot{g(t)}) =  \\
= A_{0}e^{-\beta t}((\beta^{2} - \omega^{2})\cos{\Theta} + 2\beta \omega \sin{\Theta}) \\
\text{Подставляем в уравнение (сразу сократим $A_0e^{-\beta t}$): } \ddot{x} + 2\beta\dot{x} + \omega_0^2 x = 0 \\
\cos{\Theta}(\beta^{2} - \omega^{2}) + 2\beta\omega \sin{\Theta} - 2\beta(\beta \cos{\Theta} + \omega \sin{\Theta}) + \omega^{2}_{0}\cos{\Theta} = 0 \implies  \\
\implies \omega = \sqrt{\omega_{0}^{2} - \beta^{2}}
\end{align*}
$$
