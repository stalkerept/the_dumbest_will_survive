Много поисковое сбалансированное дерево, оптимизированное для внешней памяти.
Каждый внутренний узел (кроме корня) имеет от t до 2t дочерних узлов. Содержит от t-1 до 2t - 1 ключей. Узел полон, если ключей 2t-1. Корень имеет минимум 1 ключ и 2 потомка (если не является листом). Все листья находятся на одной глубине h. Ключи в узле упорядочены.

### Структура узла:

```c
const int T = ...; // степень дерева
struct Node {
    int n;                // текущее количество ключей
    int key[2*T - 1];     // массив ключей
    Node* ptr[2*T];       // указатели на дочерние узлы (у листьев = NULL)
    Node* parent;         // указатель на родителя
};
```

### Поиск
Начинаем с корня x. В текущем узле ищем позицию i, такую что key[i-1] < k <= key[i]
Если k == key[i] - успех
Иначе спускаемся по ptr[i]
Повторяем, пока не найдём ключ или не достигнем NULL.
