Сбалансированное бинарное дерево поиска, в котором для любого узла высоты левого и правого поддеревьев отличаются не более чем на 1.
Высота дерева h ограничена: $\log_{2}(n+1)\leq h \leq 1.404 \cdot \log_{2}{n+2} - 0.328$

### Способы задания узлов
Предложены 3 варианта структуры узла:

#### С полем балансировки (balance):
balance = - 1, то левое поддерево выше на 1; 0 - высоты равны; +1 - правое выше на 1
```c
struct Node{
int balance;
int key;
Node* left, *right, *parent;
};
```

#### С полями высот поддеревьев:
```c
struct Node{
int hleft, hright;
int key;
Node* left, *right, *parent;
};
```
#### С полем высоты:
```c
struct Node{
int height;
int key;
Node* left, *right, *parent;
};
```
