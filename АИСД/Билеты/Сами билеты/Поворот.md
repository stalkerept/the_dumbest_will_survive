Локальная операция над указателями дерева, которые изменяют его структуру (высоту поддеревьев), но строго сохраняют свойства бинарного дерева поиска (порядок следования ключей: слева - меньшие, справа - большие).

### Левый 1поворот
![[Pasted image 20260607215321.png]]
Применяется к узлу X, у которого правый поток Y не является EList. Узел X опускается налево, становясь левым потомком Y (если оно было) становится правым поддеревом узла X. Указатели родителей перестраиваются.
На языке си это выглядит следующим образом:
```c
Node* left_rotate(Node* x){
	Node* y = x -> right;
	Node* B = y -> left;
	y -> left = x;
	x -> right = B;
	return y;
}
```

### Правый поворот
![[Pasted image 20260607215232.png]]
Симметричная операция. Применяется к узлу Y, у которого левый потомок X не является EList. Узел Y опускается направо, становясь правым потомком X. Правое поддерево узла X становится левым поддеревом узла Y.
На языке си это выглядит следующим образом:
```c
Node* right_rotate(Node* y){
	Node* x = y -> left;
	Node* A = x -> right;
	x -> right = y;
	y -> left = A;
	return x;
}
```

Оценка эффективности:
Чёрная высота узла bh(x) - это количество черных узлов на пути от x (не включая сам узел x) до любого листа EList.
Высота дерева (h): Высота КЧ-дерева с n внутренними узлами удовлетворяет строгому неравенству:
$$
h \leq 2\cdot \log_{2}{(n+1)}
$$
Сложность операций: Так как высота гарантировано логарифмическая, операция поисках, нахождения минимума/максимума, вставки, удаления выполняются за время O($\log{n}$) в худшем случае. Время выполнения самих повторов составляет O(1).
