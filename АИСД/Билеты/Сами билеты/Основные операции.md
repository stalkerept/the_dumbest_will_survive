**Search**(S, k) - поиск элемента по ключу
**Minimum**(S), **Maximum**(S) - поиск мин/макс ключа
**Successor**(S, x), **Predecessor**(S, x) - следующий, предыдущий элемент
**Insert**(S, x) - вставка нового элемента
**Delete**(S, x) - удаление элемента

Здесь **S** - динамическое множество, **x** - указатель на элемент, **k** -  значение ключа.
