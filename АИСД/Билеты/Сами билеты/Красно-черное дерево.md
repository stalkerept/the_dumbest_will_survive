Двоичное (бинарное) дерево поиска, у которого каждому узлу сопоставляется дополнительная информация - цвет (красный или чёрный).
Дерево называется красно-черным, если оно удовлетворяет следующим **5 свойствам**:
1. Каждый узел является либо красным (RED), либо черным (BLACK)
2. Корень дерева является черным
3. Все внешние листья (ограничители) являются черными
4. Если узел красный, то оба его потомка чёрные (два красных подряд не могут быть)
5. Все пути ведущие от любого узла к его листьям-потомкам, содержат одинаковое количество чёрных узлов

### Представление в памяти и структура узла:
В отличие от стандартного бинарного дерева поиска, узел красно-черного дерева обязательно содержит указатель на родительский узел (parent) для обеспечения возможности движения "вверх" при балансировке, а также поле цвета
На языке C структура узла выглядит следующим образом:
```c
typedef struct Node{
int color;
int key;
struct Node* left;
struct Node* right;
struct Node* parent;
} Node;
```
### Использование ограничителя (EList)
Все концевые указатели left и right внутренних узлов ссылаются на один и тот же адрес объекта EList
Цвет EList всегда ЧЁРНЫЙ. Поля key и parent для него не используются
Это позволяет избавиться от постоянных проверок на NULL в алгоритмах (на самом деле нихуя)
