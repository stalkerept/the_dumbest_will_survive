Граф G = (V, E): V — множество вершин (нод) E — множество рёбер (пар вершин)

2. Виды графов

Неориентированный

```
Рёбра не имеют направления: (u,v) ≡ (v,u)
```

Ориентированный

```
Рёбра — дуги: (u→v) ≠ (v→u)
```

Взвешенный

```
Каждому ребру сопоставлен вес w(u,v)
```

Связный

```
Между любыми двумя вершинами есть путь
```

Полный

```
Каждая пара вершин соединена ребром
```

3. Основные понятия
    
    Путь — последовательность вершин v₁, v₂, ..., vₖ, где (vᵢ, vᵢ₊₁) ∈ E
    
    Длина пути — количество рёбер (или сумма весов во взвешенном графе)
    
    Цикл — путь, где v₁ = vₖ
    
    Степень вершины — количество инцидентных рёбер (для орграфа: полустепень захода/исхода)
    
4. Представление графа в памяти
    

Матрица смежности

```
Плюсы: проверка ребра O(1), удобно для плотных графов
Минусы: память O(V²), перебор соседей O(V)
```

Списки смежности

```
Плюсы: память O(V+E), перебор соседей O(deg(v))
Минусы: проверка ребра O(deg(v))
```
