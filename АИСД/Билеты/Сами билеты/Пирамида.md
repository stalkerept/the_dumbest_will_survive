Объект-массив, представляющий почти полное бинарное дерево.
Все уровни дерева, кроме последнего, заполнены полностью. Последний уровень заполняется слева направо. Узел дерева = элемент массива

Max -heap(невозрастающая)
	Ключ родителя >= ключей потомков. A[parent(i)] >= A[i]
Min-heap (неубывающая)
	Ключ родителя <= ключей потомков. A[parent(i)] <= A[i]
Индексация (при нумерации с 0):
	 parent(i) = (i - 1)/2
	 left(i) = 2i + 1
	 right(i) = 2i  + 2
Операции поддержки свойства: Max_Heapify(A, i)
Предусловие: поддеревья с корнями left(i) и right(i) уже являются max-heap, но элемент A[i] может нарушать свойство. 
Код:
```c
int max_heap(Heap* heap, int i){
    int largest=i;
    int left=2*i+1;
    int right=2*i+2;
    if (left<heap->size && heap->data[left]>heap->data[largest]) largest=left;
    if (right<heap->size && heap->data[right]>heap->data[largest]) largest=right;
    if (largest!=i){
        int time=heap->data[i];
        heap->data[i]=heap->data[largest];
        heap->data[largest]=time;
        max_heap(heap, largest);
    }
    return 0;
}
```
Сложность: O(h), где h — высота узла i (в худшем случае O(log n))

### Создание пирамиды: Build_Max_Heap(A):
Идея: листья (i = n/2 ... n-1) уже являются пирамидами (высота 0). Обрабатываем узлы снизу вверх.

Сложность: O(n) (амортизированная, не O(n log n), т.к. большинство узлов имеют малую высоту)
