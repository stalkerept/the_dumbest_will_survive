**Элемент** списка выглядит следующим образом:
Информация + Поле связи (указатель на следующий/предыдущий элемент)

**Доступ**: Последовательный, по указателям (O(n) для n-ого элемента)

**Классификация списков:**
- По **структуре** элемента: Односвязный (next (вперед)), Двусвязный (prev (назад), next (вперед))
- По **организации**: Линейный (последний указывает на NULL), Циклический (последний указывает на первый)
- По **способу** **задания**: Указатель на начало (голову), Головной элемент (фиктивный узел).
