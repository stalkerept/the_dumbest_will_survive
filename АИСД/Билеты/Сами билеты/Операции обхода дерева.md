## Типы обходов:
### Прямой (NLR)
Корень -> Левое -> Правое
1, 2, 4, 7, 8, 3, 5, 9, 11, 6, 10
### Центрированный (LNR)
Левое -> Корень -> Правое
2, 7, 4, 8, 1, 5, 11, 9, 3, 10, 6
### Концевой (LRN)
Левое -> Правое -> Корень
7, 8, 4, 2, 11, 9, 5, 10, 6, 3, 1

Оценка эффективности: O(n) для любого обхода.
