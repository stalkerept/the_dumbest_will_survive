Динамическое множество элементов, каждый из которых состоит из пары (ключ, информация), где ключ - уникальное значение, идентифицирующее элемент, а информация - сопутствующие данные.

**Основные операции:** поиск, вставка, удаление

- [[Таблица с вычисляемым входом (Хеш-таблица)]]: 
- [[Таблица с прямой адресацией]]

Отображение в памяти:
- **Вектор** (массив) - непрерывная область, доступ по индексу O(1), хорош для прямой адресации или бинарного поиска
- **Список** - связанные узлы, последовательный доступ O(n), быстрые вставки/удаления
- **Сеть** (граф) - произвольные связи, для таблиц применяются редко
- **Хеш-таблица** - вектор корзин + списки, среднее время операций O(1)
