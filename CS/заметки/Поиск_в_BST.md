
Алгоритм поиска заданного ключа в бинарном дереве поиска, использующий свойство упорядоченности: ключи в левом поддереве меньше, в правом — больше, чем ключ текущего узла.

## Алгоритм
Начиная с корня, сравниваем искомый ключ `k` с ключом узла:
- если `k == node->key` — узел найден;
- если `k < node->key` — переходим в левое поддерево;
- если `k > node->key` — переходим в правое поддерево.

Если достигнут `NULL`, ключ отсутствует.

## Временная сложность
- В сбалансированном BST: $O(\log n)$.
- В худшем случае (дерево вырождено в цепочку): $O(n)$.

## Реализация на Си
```c
Node* search_bst(Node *root, int key) {
    Node *cur = root;
    while (cur != NULL) {
        if (key == cur->key)
            return cur;
        else if (key < cur->key)
            cur = cur->left;
        else
            cur = cur->right;
    }
    return NULL;
}
```
