
Представление графа $G = (V, E)$, при котором для каждой вершины $v \in V$ хранится коллекция смежных с ней вершин. Наиболее распространённая реализация — массив динамических списков, где индекс в массиве соответствует номеру вершины, а список содержит все вершины, соединённые ребром с данной.

## Свойства
- **Память**: $O(V + E)$ для хранения всего графа, что делает его предпочтительным для разреженных графов.
- **Перебор соседей**: за время $O(\text{degree}(v))$.
- **Проверка наличия ребра** $(u, v)$: $O(\text{degree}(u))$ без дополнительных структур.

## Реализация на Си
Вариант с динамическими массивами для списков:
```c
typedef struct {
    int *adj;    // массив соседей
    int size;
    int cap;
} AdjList;

typedef struct {
    AdjList *vertices; // массив списков по числу вершин
    int V;
    int E;
} Graph;

// Добавление ориентированного ребра u -> v
void add_edge(Graph *g, int u, int v) {
    AdjList *list = &g->vertices[u];
    if (list->size == list->cap) { /* перевыделение памяти... */ }
    list->adj[list->size++] = v;
}
```
Для неориентированного графа ребро добавляется и в `vertices[v]`.
