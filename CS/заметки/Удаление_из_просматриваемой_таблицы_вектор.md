
Операция удаления элемента по заданному ключу из таблицы, реализованной на векторе (динамическом массиве) с последовательным просмотром (сканированием) для поиска. Таблица не упорядочена, записи хранятся в порядке вставки.

## Алгоритм
1. Выполнить линейный поиск ключа `k` в массиве записей. Если ключ не найден — операция завершается (элемента нет).
2. Если запись с ключом `k` найдена на индексе `i`, все последующие элементы (индексы от `i+1` до `size-1`) сдвигаются на одну позицию влево.
3. Логический размер таблицы уменьшается на 1.

## Временная сложность
В худшем случае — $O(n)$: поиск требует $O(n)$ сравнений, сдвиг также $O(n)$. Дополнительная память не используется ($O(1)$). Подробный анализ – в [[Эффективность_просматриваемая_таблица_вектор]].

## Реализация на Си
Предполагается структура с полями `data`, `size`.

```c
typedef struct {
    int key;
    int value; // пример поля данных
} Record;

typedef struct {
    Record *data;
    int size;
    int capacity;
} ScanTable;

// Возвращает 1, если удаление успешно, 0 — если ключ не найден.
int scan_table_delete(ScanTable *t, int key) {
    for (int i = 0; i < t->size; i++) {
        if (t->data[i].key == key) {
            // сдвиг влево
            for (int j = i + 1; j < t->size; j++)
                t->data[j - 1] = t->data[j];
            t->size--;
            return 1;
        }
    }
    return 0;
}
```
