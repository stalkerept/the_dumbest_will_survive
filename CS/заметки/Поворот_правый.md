
Локальная операция перестроения двоичного дерева поиска, которая изменяет структуру узлов, сохраняя инвариант BST. Правый поворот вокруг узла `x` выполняется при условии, что `x` имеет левого потомка `y`.

## Действие поворота
- `y` становится корнем поддерева на месте `x`.
- `x` становится правым потомком `y`.
- Бывшее правое поддерево `y` (`y->right`) становится левым поддеревом `x`.

## Применение
Правый и левый повороты — базовые операции для балансировки деревьев (AVL, красно-чёрное). Они выполняются за время $O(1)$, меняя лишь несколько указателей.

## Реализация на Си
```c
// x – указатель на указатель на узел, чтобы изменить связь с родителем
void rotate_right(Node **x) {
    Node *y = (*x)->left;
    if (!y) return;               // поворот невозможен
    (*x)->left = y->right;
    y->right = *x;
    *x = y;                       // новый корень поддерева
}
```
