
Операция добавления новой записи `(key, value)` в упорядоченную таблицу с сохранением свойства упорядоченности ключей. Предполагается, что дубликаты ключей либо запрещены, либо обрабатываются отдельно.

## Алгоритм
1. Бинарным поиском найти индекс `pos`, на который должен быть помещён новый ключ. Это индекс первого элемента с ключом $\ge$ вставляемого, либо `size`, если новый ключ больше всех существующих.
2. Сдвинуть элементы с индексами `pos ... size-1` на одну позицию вправо, освобождая место.
3. Записать новую запись в `data[pos]` и увеличить `size` на 1.

## Временная сложность
- Бинарный поиск: $O(\log n)$ сравнений.
- Сдвиг элементов: $O(n)$ перемещений.
- Итоговая трудоёмкость — $O(n)$.

## Реализация на Си
```c
// Возвращает 1 при успехе, 0 если таблица заполнена.
int ordered_table_insert(OrderedTable *t, int key, int value) {
    if (t->size == t->capacity) return 0; // нет места

    int lo = 0, hi = t->size;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (t->data[mid].key < key)
            lo = mid + 1;
        else
            hi = mid;
    }
    int pos = lo; // позиция для вставки

    // сдвиг вправо
    for (int i = t->size; i > pos; i--)
        t->data[i] = t->data[i - 1];

    t->data[pos].key = key;
    t->data[pos].value = value;
    t->size++;
    return 1;
}
```
