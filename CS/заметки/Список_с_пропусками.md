
Вероятностная структура данных, реализующая упорядоченное множество (словарь) с операциями поиска, вставки и удаления за $O(\log n)$ среднего времени. Состоит из нескольких уровней связных списков.

## Структура
- Самый нижний уровень (уровень 0) содержит все элементы в отсортированном порядке.
- Каждый более высокий уровень действует как «экспресс-линия» и включает подмножество элементов предыдущего уровня. Принадлежность элемента уровню $l$ определяется случайным образом (например, подбрасыванием монетки).
- Каждый узел хранит массив указателей `forward` длиной, равной его уровню.

## Операции
Операции поиска, вставки и удаления аналогичны пошаговому спуску по уровням, начиная с самого высокого, с продвижением вперёд или вниз. Детали реализации в отдельных заметках:
- [[Поиск_skip_list]]
- [[Вставка_skip_list]]
- [[Удаление_skip_list]]

## Реализация на Си (узел)
```c
typedef struct SkipNode {
    int key;
    int value;
    struct SkipNode **forward; // массив указателей на следующие узлы по уровням
    int level;                 // количество уровней узла (индексация с 0)
} SkipNode;
```
