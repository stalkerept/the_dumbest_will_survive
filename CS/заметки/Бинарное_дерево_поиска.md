
Динамическая структура данных, организующая элементы в виде двоичного дерева с инвариантом упорядоченности: для любого узла `x` все ключи в левом поддереве меньше `x->key`, а в правом — больше. Обеспечивает эффективную реализацию таблицы (словаря).

## Инвариант и свойства
- Дерево является **бинарным деревом поиска (BST)**.
- Симметричный (in-order) обход возвращает элементы в возрастающем порядке (см. [[Симметричный_обход]]).
- Операции поиска, вставки и удаления используют бинарный поиск по дереву.
- Высота $h$ дерева определяет время операций: в сбалансированном BST $h = O(\log n)$, в вырожденном $h = O(n)$.

## Реализация на Си
Определение узла и проверка свойства BST (проверка, что дерево действительно является BST).

```c
typedef struct Node {
    int key;
    struct Node *left, *right;
} Node;

// Проверка: все ключи в поддереве [min, max]
int is_bst_util(Node *root, int min, int max) {
    if (!root) return 1;
    if (root->key <= min || root->key >= max) return 0;
    return is_bst_util(root->left, min, root->key) &&
           is_bst_util(root->right, root->key, max);
}

int is_bst(Node *root) {
    return is_bst_util(root, INT_MIN, INT_MAX);
}
```
