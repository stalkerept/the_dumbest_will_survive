
Способ организации хеш-таблицы, при котором все хранимые записи размещаются непосредственно в массиве $T[0..m-1]$ (без внешних списков). Каждая ячейка содержит либо одну запись, либо находится в состоянии «пусто» (`NIL`). При коллизии алгоритм ищет другую ячейку внутри того же массива, следуя последовательности проб.

## Пробирование
Для ключа $k$ и номера попытки $i = 0, 1, 2, \dots$ вычисляется индекс
$$ h(k, i) $$
Последовательность $\langle h(k,0), h(k,1), \dots, h(k,m-1) \rangle$ должна быть перестановкой $\{0,\dots,m-1\}$, чтобы при наличии свободных ячеек вставка всегда завершалась успешно. Конкретные стратегии:
- линейное пробирование: $h(k,i) = (h'(k) + i) \bmod m$,
- квадратичное: $h(k,i) = (h'(k) + c_1 i + c_2 i^2) \bmod m$,
- двойное хеширование: $h(k,i) = (h_1(k) + i \cdot h_2(k)) \bmod m$.

## Свойства
- Коэффициент загрузки $\alpha = n/m$ всегда $< 1$.
- Нет накладных расходов на указатели; вся память под массив.
- Удаление реализуется не физически, а через пометку ячейки как `DELETED`, чтобы не разрывать цепочки проб (детали: [[Удаление_открытая_адресация]]).

## Реализация на Си (фрагмент)
```c
#define EMPTY  -1   // признак пустой ячейки для целых ключей
#define DELETED -2  // метка удалённого элемента

typedef struct {
    int key;
    int value;
} Entry;

typedef struct {
    Entry *T;
    int m;   // размер таблицы
    int n;   // число записей
} OpenAddrHashTable;

// Вставка с линейным пробированием (пример)
int hash_insert(OpenAddrHashTable *ht, int key, int value) {
    for (int i = 0; i < ht->m; i++) {
        int idx = (key % ht->m + i) % ht->m;  // h(k,i)
        if (ht->T[idx].key == EMPTY || ht->T[idx].key == DELETED) {
            ht->T[idx].key = key;
            ht->T[idx].value = value;
            ht->n++;
            return 1;
        }
        if (ht->T[idx].key == key) {
            // обновление существующего
            ht->T[idx].value = value;
            return 1;
        }
    }
    return 0; // таблица заполнена
}
```
