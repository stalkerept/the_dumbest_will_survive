
Алгоритм поиска заданного ключа в B-дереве — сильно ветвящемся сбалансированном дереве поиска. Каждый узел содержит упорядоченный массив ключей и массив указателей на потомков (на один больше числа ключей).

## Алгоритм
1. Начиная с корня, для текущего узла `x` линейным (или бинарным) поиском находим позицию `i`, где должен находиться ключ `k` среди ключей узла.
2. Если $i \le \text{num\_keys}$ и `x->keys[i] == k`, поиск завершён успешно.
3. Если узел листовой (`x->leaf == 1`) — ключ отсутствует.
4. Иначе рекурсивно продолжаем поиск в дочернем узле `x->children[i]`.

## Временная сложность
$O(t \log_t n)$, где $t$ — минимальная степень дерева (размер узла между $t-1$ и $2t-1$ ключей). На практике глубина мала, а поиск в узле выполняется быстро.

## Реализация на Си
```c
typedef struct BTreeNode {
    int *keys;           // массив ключей
    struct BTreeNode **children; // массив дочерних узлов
    int num_keys;
    int leaf;            // 1 – лист
} BTreeNode;

// Возвращает индекс ключа в узле, либо -1
int btree_search_key_in_node(BTreeNode *x, int k) {
    for (int i = 0; i < x->num_keys; i++)
        if (x->keys[i] == k)
            return i;
    return -1;
}

// Поиск по всему дереву, возвращает узел или NULL
BTreeNode* btree_search(BTreeNode *root, int k) {
    BTreeNode *cur = root;
    while (cur) {
        int i = 0;
        while (i < cur->num_keys && k > cur->keys[i])
            i++;
        if (i < cur->num_keys && cur->keys[i] == k)
            return cur;
        if (cur->leaf)
            return NULL;
        cur = cur->children[i];
    }
    return NULL;
}
```
