
Таблица (отображение ключ–значение), в которой записи физически хранятся в массиве, постоянно упорядоченном по значению ключа (обычно по возрастанию). Инвариант: для всех $i < j$ выполняется `key[i] < key[j]` (или $\le$, если допускаются дубликаты).

## Основные свойства
- **Поиск** — выполняется бинарным поиском за $O(\log n)$ (см. [[Поиск_в_упорядоченной_таблице]]).
- **Вставка** — требует найти позицию и сдвинуть часть элементов; $O(n)$ (см. [[Вставка_в_упорядоченную_таблицу]]).
- **Удаление** — аналогично требует сдвига; $O(n)$ (см. [[Удаление_из_упорядоченной_таблицы]]).
- Выигрыш в скорости поиска по сравнению с неупорядоченной таблицей достигается ценой замедления модификаций.

## Возможное представление в Си
```c
typedef struct {
    int key;
    int value;
} Record;

typedef struct {
    Record *data;
    int size;
    int capacity;
} OrderedTable;
```
Важно: при любой модификации массив `data` должен оставаться отсортированным по полю `key`.
