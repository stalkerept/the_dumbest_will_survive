
Операция добавления нового элемента в очередь с приоритетом. В большинстве реализаций очередь с приоритетом строится на базе **двоичной кучи** (бинарной heap), которая обеспечивает логарифмическое время вставки.

## Алгоритм (для max-heap)
1. Поместить новый элемент в конец внутреннего массива кучи (последний лист).
2. Выполнить **просеивание вверх** (sift-up): пока ключ элемента больше ключа его родителя, обменять их и подняться выше.
3. После завершения снова выполняется свойство кучи (родитель больше потомков).

## Временная сложность
$O(\log n)$, так как высота двоичной кучи $\lfloor \log_2 n \rfloor$.

## Реализация на Си
```c
typedef struct {
    int *data;
    int size;
    int capacity;
} PriorityQueue;

void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }

void insert(PriorityQueue *pq, int key) {
    if (pq->size == pq->capacity) return; // нет места
    pq->data[pq->size] = key;
    int i = pq->size;
    pq->size++;

    // sift-up
    while (i > 0 && pq->data[i] > pq->data[(i - 1) / 2]) {
        swap(&pq->data[i], &pq->data[(i - 1) / 2]);
        i = (i - 1) / 2;
    }
}
```
